# Portfolio Assets

Use this directory for the polished artifacts that support the portfolio version of AgentQuest.

Recommended contents:

- `benchmark_report.md`: generated by `scripts/render_benchmark_report.py`
- `benchmark_report.json`: saved metadata for the generated report
- `architecture_diagram.png`: one simple system diagram
- `streamlit_validator_view.png`: screenshot showing raw output, parsed tool call, and validator verdict
- `self_learning_notes.md`: short write-up comparing baseline and self-learning runs
- `preset_comparison.png`: optional chart or table image for the flagship post

Suggested workflow:

1. Run the benchmark slice for each target model.
2. Generate `benchmark_report.md`.
3. Capture one or two screenshots from the Streamlit app.
4. Add a short self-learning write-up after the baseline benchmark is stable.

Keep this directory small and intentional. It should contain showcase artifacts, not raw run logs.
