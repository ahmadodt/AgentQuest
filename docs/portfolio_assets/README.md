# Portfolio Assets

This folder contains screenshots and visual assets used for the AgentQuest portfolio page, GitHub README, and LinkedIn posts.

## Screenshot Groups

### Benchmark UI

- `benchmark_UI.png` - benchmark configuration screen for selecting the model, campaign, characters, and prompt settings.
- `benchmark_UI_2.png` - benchmark run screen showing progress, pass/fail counts, and scene-level status.

### Human Player UI

- `human_player_choose_tool.png` - human-player tool selection with the available arguments.
- `human_player_scene_UI.png` - scene-level human-player view before choosing an action.

### Inspect Run

- `inspect_run_UI.png` - interactive model-run setup and inspection screen.
- `inspect_run_running_full_campaign.png` - full campaign execution in progress.
- `inspect_run_finished_campaign.png` - completed campaign progress and summary view.
- `inspect_run_finished_campaign_2.png` - completed campaign result and context details.
- `inspect_run_finished_campaign_3.png` - additional completed campaign diagnostics.

### Preset Comparison

- `preset_comparison.png` - information-ladder comparison of `BLIND_ADVENTURER`, `BATTLE_PLAN`, and `FULL_INFO`.
